Mohar check

Rebuilds an exam's verdicts straight from the public Arkiv RPC, in your browser. This page is one file with no build and no server: save it (Ctrl+S) and it keeps working even if every Mohar site is gone.

If set, only the addresses the exam body lists at https://<website>/.well-known/mohar.json count, and the address below is ignored.
Only seals created by this address count. Check it against the exam body's own website.
Same rules as verify.mjs and the main site: a witness counts only if it was sealed before the earlier of the announced start and the reveal, and a question counts only if the revealed text matches its seal. Source: github.com/vidit-16/mohar
